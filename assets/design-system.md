# Shovo127 visual design system

## Design intent

Modern Engineering Command Center × Cinematic Technology Portfolio.

The identity connects physical engineering, software tools and learning technology. It should feel engineered and editorial rather than like a collection of badge widgets.

## Typography

- Use system-safe sans-serif typography for artwork.
- Use monospace only for technical labels, identifiers and metadata.
- Keep README body copy in GitHub's native Markdown typography.
- Avoid tiny decorative text that becomes unreadable on mobile.

## Composition

- Use a strong hierarchy and generous negative space.
- Keep one focal object per scene.
- Keep repeated animation dimensions and framing consistent.
- Use high-contrast text and avoid encoding essential information only by colour.
- Prefer a few informative visual blocks over repeated full-width decorative banners.

## Motion

- Motion must be visibly intentional: turntable rotation, camera movement, lighting variation or meaningful environmental movement.
- Avoid rapid flashing, strobing and imperceptible motion.
- Keep GIFs compact and use a shared palette across frames to avoid colour flicker.
- Decorative GIFs need meaningful alt text and must not claim interactivity.
- GitHub README does not execute arbitrary JavaScript; an embedded GIF is not a playable game.

## Data visualisation

- Use verified GitHub data only.
- Label language distributions as code volume, never skill.
- Show source and generation timestamp.
- Represent unavailable metrics as unavailable, not zero.
- Contribution-intensity colour must use actual counts and a documented scale.
- A decorative isometric city must not be labelled as contribution analytics.

## GitHub rendering constraints

- Use relative repository paths for all primary images.
- Use Markdown and conservative HTML supported by GitHub README rendering.
- Do not rely on custom CSS, scripts, external image generators or remote image CDNs.
- Keep official websites and repositories as ordinary navigation links.

## Art direction

The Blender pipeline uses product-photography lighting: broad cool key light, soft fill and restrained warm rim. Materials should read as metal, glass, ceramic or matte polymer, with plausible shadows and bevels. Avoid generic neon grids and random floating code.
